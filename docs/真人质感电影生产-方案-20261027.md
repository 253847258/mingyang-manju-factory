> 日期：2026-10-27
> 范围：写实人物短剧/电影，从人设 → 关键帧 → 视频 → 成片

---

## 一、四层能力盘点

| 层 | 现状 | 判断 |
|---|---|---|
| 人设一致性 | 演员档案 + 多版本关键帧 + pHash 抽检 | 有基础，**缺多角度角色圣经** |
| 写实关键帧 | Seedream 5.0 pro（被账号限额暂停）/ Pollinations（免费，中文理解差、会限流） | 能出真图，**稳定性不足** |

## 二、本次已实现

### 1. 电影质感出图预设（桥接层）

`style=cinematic` 时自动追加：

```
cinematic film still, photorealistic, natural skin texture, subtle film grain,
shallow depth of field, ARRI Alexa 35mm, dramatic key light, color graded, 24fps motion feel
```

### 2. 电影感渲染档（后期）

| 项 | 标准档 | 电影感档 |
|---|---|---|
| 帧率 | 30fps | **24fps** |
| 调色 | 无 | `eq=contrast=1.06:saturation=1.04:gamma=0.98` |
| 颗粒 | 无 | `noise=alls=4:allf=t` |
| 响度 | -16 LUFS | **-14 LUFS** |

编辑器工具栏新增「🎬 电影感」开关。

### 3. 验证

- `test-edit-render` 13/13：电影感输出实测 **24/1 fps**，版本正常落库
- 出图桥接实测返回 `style=cinematic`
- 全套回归 **74/74** 通过

## 三、必须如实说明的限制

1. **中文提示词**：Pollinations(flux) 对中文理解很差——"35岁中国男演员…"生成成了风景图；同参数英文提示词才接近人物。Seedream 原生支持中文，但被账号限额卡住。
2. **真人视频**：Seedance 明确拒绝"可能是真人"的首帧。真演员质感视频要么换 Kling/Runway/Luma，要么走动漫化/风格化。
3. **一致性**：单张参考图不足以稳定跨镜长相，需要多角度角色圣经。
4. **免费引擎会限流**：连续出图会返回 402/503。

---

## 四、推荐的真人质感生产流水线

1. **角色圣经**：同一演员生成正面 / 3/4 侧 / 侧面 / 背面 + 3 种表情，锁定 seed 与参考图
2. **写实关键帧**：Seedream（中文）+ 角色参考图 + cinematic 预设 + 负向词（plastic skin / cartoon / CGI / over-smoothed）
3. **视频**：
   - 真人写实 → Kling 2.5 / Runway Gen-4 / Luma（generic-http 预设已内置）
   - Seedance → 仅用于动漫化/风格化人设
4. **后期**：电影感档（24fps + 颗粒 + 调色 + -14 LUFS），必要时加 2.39:1 遮幅
5. **质检**：跨镜人脸 pHash、闪烁/抖动、运动伪影、字幕 CPS

---

## 五、下一步（按价值排序）

1. **多角度角色圣经生成器**（提升一致性，最影响"像不像同一个人"）
2. **中文提示词自动英译**（让免费引擎可用；或直接用 Seedream）
3. **Kling / Runway / Luma 视频预设**（真人视频绕开 Seedance 审核）
4. **2.39:1 遮幅 + LUT 调色文件**（电影感再上一档）
