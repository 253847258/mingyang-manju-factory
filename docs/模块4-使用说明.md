> 目标：把「剧本工厂」（模块3）产出的**分镜表**逐镜变成 **关键帧 → 镜头视频 → 整集成片 mp4**，形成「明星定妆 → 小说 → 剧本分镜 → 成片」的完整闭环。

## 2. 界面结构（三段式）

```
┌ 左栏（剧本 → 剧集）────────┬ 主区（当前剧集制作台）───────────────┐
│ 🎞 制作台  ⟳              │ ① 剧集头：S01E001·雾夜碎牌 + 出图/视频后端徽章 │
│ 关键帧 / 视频 / 成片 / 失败 │ ② 工具条：渲染/生成/合成(按包装)/🎁包装/🚀流水线 │
│ ▸ 雾港谜案·漫剧版 SC-0001   │ ③ 提示条：后端未就绪 or 本地运镜说明      │
│   S01E001 33镜 🖼33/33 🎬33/33 成片 │ ④ 统计条：镜头数/时长/进度条/成本级 │
│   S01E002 0镜  🖼0/0  🎬0/0 已规划  │ ⑤ 筛选条：状态 / 成本级 / 倍率 / 全选 │
│   S01E003 …                │ ⑥ 镜头网格（卡片，每张 252px 起自适应）   │
│   S01E004 …                │ ⑦ 整集成片列表（播放器 + 字幕/音轨徽章）   │
└───────────────────────────┴────────────────────────────────────┘
        任务浮层（右下角，可同时跟踪多个任务，含整季流水线）
   弹窗：🎁 成片包装（字幕/音轨/画面）　🚀 整季流水线（剧集/阶段/预估/报告）
```

### 左栏

- 顶部一排统计：**关键帧 / 视频 / 成片 / 失败数**（按镜头数收敛；鼠标悬停有说明）。
- 剧本项目行：标题 + `SC-0001` + 画风 + `X集·Y镜` + `🖼 已出关键帧镜头数` + `🎬 已出片镜头数`（有整集成片时额外显示「成片 N」徽标）。
- 点项目行 → 选中并展开剧集列表；点行首 **▸/▾ 箭头** → 单独收起/展开（不影响当前选中）。
- 剧集行：`S01E001 雾夜碎牌 · 33镜 · 🖼33/33 · 🎬33/33`，有整集成片显示「成片」徽标，已出了剧本但没分镜的集显示状态标签（已规划 / 有剧本），并带一条关键帧进度条。

### 主区（选中某集后）

**① 剧集头**：集号 / 集标题 / 剧本 ID / 画风 / 画幅比例（漫剧 `9:16`、电影 `21:9` 等）/ 目标时长 / 剧本来源 / 镜头数 / 分镜总时长；右上角两枚后端徽章：

| 徽章 | 绿色（就绪） | 黄色（未就绪） |
|---|---|---|
| 🖼 出图：`backend` | 可出关键帧 | 悬停显示 `note`，点击看详情并可跳「设置」 |
| 🎬 视频：`backend` | 可出片 | 悬停显示 `note`，点击看详情 / 探测 / 试渲染 |

**② 工具条**

| 按钮 | 行为 |
|---|---|
| 🖼 渲染本集关键帧 | `POST /api/render/keyframes`；有勾选时只提交勾选的镜头，否则提交当前筛选出的全部镜头 |
| 🎬 生成本集视频 | `POST /api/render/videos`；若有镜头缺关键帧，先弹出中文确认框，可选「自动先渲染关键帧再出片」（前端串行调用两个接口） |
| 🎞 合成整集成片（按包装） | `POST /api/render/assemble`，提交时带上**当前包装设置**（`finish` 字段，默认值来自 `GET /api/render/finish-status`）；一镜未出片时会先提示先生成视频 |
| 🎁 成片包装 | 打开包装面板弹窗（字幕 / 音轨 / 画面），详见下文 |
| 🚀 整季流水线 | 打开整季流水线面板弹窗（多集批量生产），详见下文 |
| ⟳ 重做（覆盖） | 开关。开=已存在的关键帧/视频重新生成；关=已存在的自动跳过（后端返回 `skipped`） |
| ⬇ 导出本集 CSV / JSON | 直接新标签页打开 `/api/scripts/:id/export?format=csv&episode=S01E001`（模块3 的导出接口） |
| 🔍 探测视频后端 | `POST /api/video-backend/probe`，弹窗显示后端、在线状态与中文原因，并提供「🧪 单镜试渲染」 |
| ⟳ 刷新 | 重新读取 overview + 本集看板 |

工具条下方有一行**当前包装摘要**（例：`🎁 当前包装：字幕 烧录进画面（Noto Sans Mono CJK SC 22px） · 音轨 静音轨 · 淡入 0.4s / 淡出 0.6s`），点「🎁 成片包装」即可修改。

**③ 提示条**（按后端状态自动出现）

- 视频后端 `ready=false`：黄色告警，说明后端名、`note` 与「去设置」按钮，此时出片会失败。
- 视频后端 = `placeholder`：蓝色说明「当前用本地 ffmpeg 运镜占位成片」，并明确写出**必须先有该镜的关键帧**；同时给出「探测」「单镜试渲染（3 秒，不落库）」「配置视频后端」。
- 出图后端 `ready=false`：黄色告警 + 去设置。

**④ 统计条**：镜头数 / 目标时长 / 已生成视频时长 / 关键帧 `已出/总数` + 进度条 / 视频 `已出/总数` + 进度条 / 成本级 `L·M·H` 分布。

**⑤ 筛选与批量**

- 状态筛选：`全部 / 缺关键帧 / 缺视频 / 失败`（每个标签带数量）。
- 成本级筛选：`L / M / H`（可多选，带数量）。
- 运镜倍率：`1× / 1.5× / 2×`（对应接口 `motionScale`，视频时长 = 分镜时长 × 倍率，单镜上限 12 秒）。
- `全选 / 反选 / 清空` + 「已选 N 镜」计数 + 「🖼 渲染选中关键帧」「🎬 生成选中视频」。
- **提交语义**：勾选了镜头 → 只提交勾选的；一个都没勾 → 提交当前筛选出的镜头（状态 + 成本级共同过滤）。筛选条会实时显示「当前显示 N 张卡片 / 共 M 镜」。

**⑥ 镜头网格**（超过 120 张只渲染前 120 张，底部「加载更多」每次追加 120 张）

每张卡片包含：

- 头部：勾选框 / `#镜号` / 景别 / 运镜 / 时长 / 成本级标签，右上角状态徽章（`生成中…` 呼吸动画 / `失败` / `已出片` / `待出片`）。
- **关键帧缩略图**（点击放大，弹窗内可新标签页打开或下载）；没有关键帧时显示占位图 + 「渲染」按钮。
- **视频**：有片时内嵌 `<video controls muted preload="metadata">`，并在下方显示 **`分镜时长 → 视频时长`**（例 `3秒 → 3秒`）、**该镜运镜**（`vid.motion`，缺省回退分镜的 `move`，例 `🎥 固定 远景`）、后端 / 模型 / 「⬇ 下载」；没片时显示「🎬 未出片（缺关键帧）」+「出片」按钮。
- 英文提示词前 2 行（等宽小字，点击即复制全文）。
- 出场角色头像（`cast[].cover`）+ 姓名，无角色时显示「无指定角色」。
- 操作按钮：`🖼 出图` `🎬 出片` `📄 复制提示词` `🗑 删除渲染`。
- 失败时卡片描红并展开错误行：中文 `error` 文案 + 「重试」+「清除失败记录」。重试会自动判断是出图还是出片失败。
- 底部一行元信息：场次 / 时间 / 机位 / 转场 / 关键帧后端与生成时间。
- 单镜 `🖼 出图`、`🎬 出片` 与「重试」**总是覆盖**（不受 `⟳ 重做（覆盖）` 开关影响），因为点击本身就是「重新生成这一镜」。

**⑦ 整集成片列表**：默认显示本集成片，可切换「查看本剧本全部成片」（`GET /api/render/films?scriptId=`）。每条显示 `FM-xxx` / 集号 / 状态标签 / 时长 / 镜头数 / 文件大小 / 后端 / 生成时间 / 「▶ 新标签页播放」/「⬇ 下载」，并内嵌 `<video controls>` 播放器（竖向成片最高 400px，不会撑爆页面）；合成失败的行会显示中文 `error`。

每行还会从 `episode_films.meta` 解析并显示**包装徽章**（meta 是 JSON 字符串，旧成片没有包装信息时优雅降级）：

| 徽章 | 来源 | 例子 |
|---|---|---|
| 💬 字幕 | `meta.subtitles.{applied,cues,mode,reason}` | `字幕 15 条 · 烧录进画面`／`无字幕（该集没有台词，跳过字幕）` |
| 🔊 音轨 | `meta.audio.{mode,clips}` | `静音轨`／`配音（TTS） · 33 段`／`背景乐（BGM）` |
| 缺 N 镜 | `meta.missingShots` | 合成时缺视频的镜头数 |
| 流水线 | `meta.pipeline` | 该成片来自「整季流水线」 |

### 🎁 成片包装面板（弹窗）

打开方式：工具条「🎁 成片包装」、成片列表里的「🎁 成片包装」、流水线面板里的「🎁 调整包装设置」。打开时若还没读过 `GET /api/render/finish-status` 会先拉一次，**默认值 = 后端配置**（`finish`），字体默认显示后端探测到的中文字体。

| 分区 | 控件 | 说明 |
|---|---|---|
| 💬 字幕 | 启用字幕开关 | 关闭后合成不做字幕（`subtitles:false`） |
| | 模式：烧录进画面 `hard` / 软字幕轨 `soft` / 不做字幕 `none` | `hard` 走 `subtitles` 滤镜重编码；`soft` 内嵌 `mov_text` 字幕轨不重编码；`none` 跳过 |
| | 字体输入 + 「用探测字体」 | 留空=后端自动挑中文字体；右侧常驻显示后端探测结果（如 `Noto Sans Mono CJK SC`） |
| | 字号 / 底部边距 / 包含动作描述 | 对应 `subtitleSize` / `subtitleMarginV` / `subtitleIncludeAction`（没有台词的镜头用动作描述当字幕） |
| | **👁 预览字幕** | `POST /api/render/preview-srt`，显示「共 N 条字幕 / 总时长 / 字体」+ 等宽字体渲染的 **SRT 前 60 行**（超出提示「还有 N 行未显示」）；字幕为空时给出中文提示 |
| 🔊 音轨 | 静音轨 `silent` / 配音 `tts` / 背景乐 `bgm` | 三选一，与后端 `finish.audio` 一致 |
| | （TTS）状态徽章 + 🔈 试听 + 🔍 探测后端 + ⚙️ 去设置 | 徽章显示 `backend/ready/note`；试听调 `POST /api/tts-backend/test` 并用 `<audio controls autoplay>` 播放；未就绪时给中文说明并引导去设置页（合成会自动回退静音轨并在 meta 的 `audio.reason` 写明） |
| | （BGM）上传控件 + 音量滑块 + 试听 | 上传走 `ctx.api.upload(file)`，把返回的 `path` 存进 `finish.bgmPath`；滑块实时显示百分比，存进 `bgmVolume`（0~1） |
| 🎬 画面 | 淡入 / 淡出秒数 | `fadeIn` / `fadeOut`，0 = 不做；淡出以成片总时长为基准 |
| 底部 | 💾 保存为默认 | `PUT /api/settings {finish:{...}}`，写成后端默认，下次打开/下次生产自动带出 |
| | ✅ 应用到本集封装 | 只改本次会话的包装设置（并即时刷新工具条摘要），不落配置文件；从「合成整集成片」进入时可直接「应用并封装本集」 |

所有控件改动只作用于**本地working copy**，点「保存为默认」才落盘，避免误改全局配置。

| 底部 | ▶ 开始整季生产 | 先弹中文确认框（列出目标集、阶段、成本级、是否离线、包装摘要与预估值），确认后 `POST /api/render/pipeline` |

### 📋 整季生产报告（弹窗，流水线完成后自动弹出）

- 顶部：`✅ 整季生产完成` + 剧本 / 目标集数 / 总用时（`startedAt→finishedAt`）+ 一行汇总（集数 / 成片 / 失败 / 新出分镜镜头 / 警告）。
- 表格逐集一行：**剧集**（集号+集名）、**分镜**（镜数 / 已存在跳过）、**关键帧**（成功/总数 · 跳过）、**视频**（成功/总数 · 跳过）、**成片**（时长 · 大小 + 字幕模式/音轨模式）、**耗时**（`elapsedMs`）、**警告 / 错误**（`error` 优先，其次 `warnings`，行标红）。
- 底部：`汇总警告（N）` 明细（最多列 12 条）。
- 按钮：**📂 成片目录**（列出本次产出的成片文件：▶ 播放 / ⬇ 下载 + 可复制的目录路径）、**⟳ 刷新看板**（重新读 overview + 本集看板）、关闭。

### 任务浮层（右下角）

- 每次提交任务后即时出现：标题、状态（排队中 / 进行中 / 已完成 / 失败 / 已取消）、`进度 done/total`、百分比、进度条、错误摘要。
- 支持**同时跟踪多个任务**（关键帧 / 视频 / 合成 / **整季流水线**）；进行中的任务可「取消」（`POST /api/jobs/:id/cancel`），完成 4 秒后自动收起，也可手动「关闭」。
- 切到别的模块再切回制作台，会自动接管服务端仍在跑的制作任务（`GET /api/jobs`，含 `pipeline` 类型）。
- 任务进行中，看板会**节流刷新**（≥5 秒一次，且有视频正在播放时跳过刷新，避免打断播放），任务结束后自动刷新统计、看板与成片列表。

## 3. 标准制作流程

1. **选剧本、选集**：左栏点开剧本 → 点某一集（会自动跳到第一集有分镜的剧集）。
2. **出关键帧**：`🖼 渲染本集关键帧`（或先勾选几个镜头试水，或单镜点「渲染」）。出图后端为 `placeholder` 时产出本地占位 SVG 定妆卡，配置真实出图后端后即为真实画面。
3. **出镜头视频**：`🎬 生成本集视频`。
   - 视频后端 = `placeholder`：本地 ffmpeg 把该镜关键帧做推/拉/摇/移/跟拍等运镜生成 mp4，**必须先有该镜关键帧**；缺图时弹确认框，选择「先自动渲染关键帧」即可串行完成。
   - 视频后端 = `comfyui-h3`：走云端 ComfyUI + MiniMax H3，**只填实例地址即可**（工作流路径留空 → 自动用内置官方模板）。该镜有关键帧就用**首帧驱动**（关键帧光栅化后上传作首帧，画面与关键帧一致），没有则文生视频；自动挂 turbo LoRA 4 步（≈45s/条）；产物自带音频。提交前会拉 `/object_info` 预检节点/必填项/模型清单，不通过就在卡片上给中文原因、不会白跑一次 400；超时自动 `/interrupt`。
   - 视频后端 = `generic-http`：任意厂商视频 API（请求体模板 + 响应字段路径 + 异步轮询），关键帧以 base64 回填模板。
   - 想省钱可先用成本级筛选（如只勾 `L`）或只勾少量镜头分批出片；`H 全动态` 镜头最贵，适合先出 `L/M` 看效果。
4. **合成整集成片**：先点「🎁 成片包装」确认字幕/音轨/淡入淡出（可先「👁 预览字幕」看效果），再点 `🎞 合成整集成片（按包装）` → 按镜头顺序拼接已生成的视频，并依次套上字幕 → 音轨 → 淡入淡出 → 输出 mp4，完成后出现在底部成片列表（带字幕/音轨徽章），可直接播放/下载。
   - 想让这套包装成为全局默认：在包装面板点「💾 保存为默认」。
5. **整季批量生产**（可选）：`🚀 整季流水线` → 选剧集/阶段/成本级 → 看预估 → 「▶ 开始整季生产」，任务在后台跑，右下角浮层与面板同步进度，完成后自动弹**生产报告**。
6. **导出与交付**：`⬇ 导出本集 CSV/JSON` 拿分镜表，成片列表「⬇ 下载」拿 mp4。

### 推荐的两条路径

- **省钱先试链路**：整季流水线里保持「🧪 离线试跑」开启，阶段只勾「生成分镜 + 封装成片」，目标成本级只勾 `L/M` → 不调用任何模型即可跑通「分镜 → 成片」。
- **只补包装**：素材都齐了（如 `S01E001` 已有 33 镜视频），阶段只勾「封装成片」、剧集只勾该集 → 约 1 分钟产出带字幕/音轨的成片（本机 33 镜实测 48 秒）。

## 5. 关键规则与坑

1. **本地运镜必须先有图**：`placeholder` 后端把关键帧做运镜，没有关键帧的镜头会直接报「缺少可用关键帧（请先渲染关键帧，或改用文生视频后端）」，界面上该镜会出现红色错误行。点「生成本集视频」前若存在缺图镜头，界面会先提示是否自动先出图。
2. **覆盖开关**：默认不覆盖，已存在的关键帧/视频会整镜跳过（任务结束时提示 `N 镜已跳过`）。想重做整集请先打开 `⟳ 重做（覆盖）`。
3. **单镜按钮总是覆盖**：卡片上的 `🖼 出图` / `🎬 出片` / `重试` 对单镜强制覆盖，符合「我就是要重渲这一镜」的直觉。
4. **成本级与倍率只影响视频任务**：`onlyCostLevels` 与 `motionScale` 只在 `POST /api/render/videos` 生效。
5. **合成只包含已出片的镜头**：缺失镜头数会在任务完成的提示里以「合成时缺少 N 镜视频」给出，成片时长 = 已出片镜头时长之和。
6. **删除渲染不可恢复**：`🗑 删除渲染` 会删除该镜的全部关键帧与视频记录及磁盘文件；只删单条也可用接口 `DELETE /api/render/renders/:id`。
7. **界面计数按镜头数收敛**：后端 `counts` 统计的是渲染行数（同一镜重做会产生多行），左栏显示时按镜头数封顶，避免出现「34/33」这种数字；真实行数可用「失败」与卡片错误行核对。
8. **大列表**：镜头超过 120 张只渲染前 120 张卡片（「加载更多」追加），避免整集 100+ 镜时卡顿。
9. **切换剧集清空勾选**：换集时勾选与「加载更多」进度重置；同一集内的自动刷新会保留勾选。
10. **视频正在播放时不整块重绘**：任务进行中的自动刷新会跳过，手动「⟳ 刷新」不受限制。

## 7. 已知限制

1. **未跑整集批量出片验证**：按约定只验证了单镜出图/出片，33 镜整集任务的耗时与并发表现取决于 `config.json` 里 `video.concurrency`（默认 1）与 ffmpeg 性能。
2. **进度粒度**：任务进度来自后端 `job.progress`（按镜头数推进），单镜内部（云端排队、ffmpeg 编码）没有更细的阶段提示。
3. **取消是协作式的**：点「取消」只是标记任务取消，正在跑的那一镜会跑完当前步骤，已成功落库的镜头不会回滚。
4. **勾选不跨集保留**：切换剧集后勾选清空；同一集内自动刷新保留。
5. **自动刷新节流**：任务进行中最多每 5 秒刷新一次看板，且检测到有视频正在播放时跳过；想立刻看到最新状态可手动「⟳ 刷新」。
6. **单镜操作不做二次确认**：`🖼 出图` / `🎬 出片` 立即提交（单镜、耗时短），只有批量、删除渲染、自动先出图这些有副作用的动作会弹确认框。
7. **成本级 H 在演示数据中为空**：`SC-0001` 只有 `L/M` 镜头，H 相关筛选与 `onlyCostLevels:['H']` 需等实际数据中出现 H 级镜头才能看到效果。
8. **云端后端探测已升级为深度探测**：`探测` 不只判断 `/system_stats` 可达，还会拉 `/object_info` 校验内置工作流的每个 `class_type` 与必填项、检查模型权重是否在实例清单里、判断视频节点是否支持首帧输入、检查 turbo LoRA 是否可用，并一次给出中文结论（缺哪个节点/哪个模型、走 i2v 还是 t2v）。真正的执行失败仍会作为中文错误出现在卡片上，错误里会带上模板名与 `prompt_id`。
9. **云端视频链路有离线自检兜底**：`node tests/test-comfy.js`（52 项）用一个假 ComfyUI 实例覆盖预检拦截、模板自动选择与回退、SVG→PNG 光栅化上传、turbo/比例映射、超时中断、503 探测文案，因此**实例掉线时也能验证代码是否正确**。
10. **本集导出走模块3 接口**：若模块3 路由未安装（服务降级 501），导出按钮会打开一个 JSON 错误页，不影响制作台其它功能。
11. **占位素材**：出图后端为 `placeholder` 时关键帧是本地 SVG 占位卡（画面内含镜号/参数文字），成片即由这些占位图运镜而来；配置真实出图后端后同一套按钮直接产出真实画面。

### 第二轮补充（成片包装 / 整季流水线）

12. **「📂 成片目录」是文件清单而非目录浏览**：服务端 `/data` 静态挂载不支持目录索引（请求目录返回 404 JSON），所以该按钮弹窗列出本次产出的成片文件（▶ 播放 / ⬇ 下载）并提供可复制的目录路径，不做浏览器内的目录树。
13. **软字幕轨需要播放器支持**：`soft` 模式内嵌 `mov_text` 字幕轨，Chrome 内置播放器默认不显示，需用支持字幕轨的播放器（VLC / mpv / 部分网页播放器）打开；想让字幕「一定看得见」请用 `hard`。
13. **TTS 试听依赖后端就绪**：本机 `tts.backend=none`（未启用配音），试听必然失败并给出中文原因，界面对应给出「去设置」引导；真正的配音效果需要在设置页配置 openai / generic-http 后端后验证。
14. **未跑整季视频生产**：按约定只用 `S01E001 + stages:['assemble']` 实跑了 1 集（约 49 秒）验证链路；`keyframe/video/storyboard` 阶段在多集、上百镜下的耗时、并发与费用未做实跑验证（预估来自 `estimate` 的经验值）。
15. **「🧪 离线试跑」默认开启**：它把 `provider:'mock'` 传给后端的**分集规划/分镜**环节（走离线规则、不调用模型）；关键帧与视频仍按当前后端真实执行，所以「离线」不等于「完全不出图不出片」，想只看分镜效果请把这两类阶段取消勾选。
16. **流水线进度是粗粒度**：`job.progress` 由后端按集/按镜推进（结束才到 100），面板里的百分比只在每次轮询（约 1.2 秒）后刷新，无法显示「当前正在处理的镜号」；详细日志在服务端 stdout。
17. **报告里的「—」**：未勾选的阶段在报告里显示 `—`（如只做封装时「分镜/关键帧/视频」列为空），这是「本次未执行」而非失败；`summary.shots` 只统计本次新生成的分镜镜头数。
18. **包装设置分两层**：面板里的改动默认只作用于「本次会话」（点「应用到本集封装」）；要让下一次打开/下次生产也带上，必须点「💾 保存为默认」（写入 `config/config.json` 的 `finish` 段）。
