# 后期精修 · 使用说明（P0）

> 模块入口：顶部导航「✂️ 后期精修」或 `#/editor`
> 开关：`config/config.json` → `edit.enabled`（默认关闭；当前已开启）
> 渲染：全部本地 ffmpeg，**零 API 费用**

## 一、能做什么

- **多轨时间线**：主轨 / 画中画（ov1）/ 字幕轨 / 配乐音效轨
- **逐片段精修**：入点/出点裁剪、拖拽调序、分割（S）、删除
- **转场**：cut / dissolve（xfade）/ fade-to-black
- **字幕**：分镜对白自动生成字幕片段，可逐条改文案；渲染时 libass 烧录
- **画中画**：缩放、透明度、位置（`x/y` 走 ffmpeg overlay 表达式）
- **音量**：逐片段 dB + 轨级 dB；渲染时 loudnorm 到 -16 LUFS
- **版本树**：每次渲染生成 vN，可回放、可恢复
- **审片**：播放器暂停打点 + 画面圈注（归一化坐标）+ 分类/严重级 + 状态流转
- **审计**：创建/保存/同步/渲染/恢复/审片/批注 全部留痕（操作人署名）
- **画布同步**：画布变更后人工确认再同步，不自动覆盖精修

## 二、审片状态机（硬门禁）

```
draft ──送审──> review ──通过──> approved ──锁定──> locked
  ^               │                    │
  └────退回───────┘                    └──退回重审──> review
```

- 送审前必须已有可播放成片
- 送审/通过前：未处理的 `blocker` 必须清零；通过还要求 `major` 清零
- 锁定后时间线只读，任何修改都会被拒绝（需新建版本）

## 四、数据与回滚

新增表：`edit_timelines`、`edit_tracks`、`edit_clips`、`edit_versions`、`review_comments`、`audit_log`；
`episode_films` 增加 `timeline_id / version_no / parent_film_id / review_status / operator`。

- 首次建表前自动备份：`_archive/backup-<时间戳>/`（db + wal + shm + config.json）
- 回滚：停服 → 恢复备份 → 删除 6 张新表 → 移除 `episode_films` 新增列（或直接恢复备份）
- 旧链路（制作台原生成片）不受影响：新表不被旧代码读取

## 五、已知限制

1. **无鉴权**：`operator` 是本机署名，不是安全边界，不防冒用。
2. **预览基于最近一次成片**：未渲染的改动看不到画面；点「渲染成片」后才有新版本。
3. **分割按片段中点**（当前播放头不参与帧级映射）；需要精确切点时直接改入点/出点。
4. **画中画位置**用 ffmpeg overlay 表达式（默认 `W-w-40:40`），暂未提供拖拽定位。
5. **渲染串行**：一次只跑一个渲染任务，避免 CPU 打满。

## 七、P1：专业后期衔接（工程包 + 回灌）

### 导出工程包

编辑器顶部「📦 工程包」→ 后台生成 zip（`data/deliveries/edit-<code>-<时间戳>.zip`），包含：

```
timeline.edl   CMX3600
timeline.xml   FCP7 XML（含 <in>/<out> 与 edit-in 标记）
timeline.otio  OpenTimelineIO（source_range 保留裁剪点）
timeline.json  站内完整时间线（多轨）
manifest.json  素材映射（源文件 ↔ 代理）
manifest.csv   同上表格版
proxies/       540p 代理素材（时间轴与源素材一致）
README.txt     导入与回链接说明
```

### 回灌差异

编辑器顶部「📥 导入时间线」→ 粘贴/选择 FCP7 XML 或 OTIO：

- 先返回**差异计划**（dry-run）：新增 / 移除 / 重排 / 裁剪，并标注每段是否匹配到站内镜头
- 确认后才应用；应用前会检查 `doc_version`（冲突 409），主轨覆盖，画中画/字幕/音频轨保留

### 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/edit/timelines/:id/package` | 异步生成工程包，`{withProxy:true,height:540}` |
| POST | `/api/edit/timelines/:id/import` | `{content}` → 差异计划；`{content,apply:true,doc_version}` → 应用 |

### 已验证

- 2 秒夹具：zip 含 6 类文件 + 2 个代理；FCP7 往返 `sourceIn` 保留；交换顺序后被识别为重排并正确应用
- 真实 33 镜：工程包 73 个条目 / 33 个代理 / 1.8MB；用包内 OTIO 回灌 **0 差异**

### 已知限制

- FCP7 解析器本身不读 `<in>`：本项目通过 `edit-in` 标记保证往返；外部 NLE 若删掉该标记，裁剪入点会按「无信息」处理（不会误报，但也无法恢复）
- 代理素材按源文件 sha1 命名，源文件不变则复用，不会重复转码
